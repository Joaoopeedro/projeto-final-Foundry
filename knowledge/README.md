# Base de Conhecimento — Duarte Advocacia IA Jurídica

Esta pasta armazena os arquivos de referência e base jurídica do escritório.

- Caso possua o arquivo original `Agente_IA_Advocacia_Base_de_Conhecimento.docx`, ele pode ser mantido aqui para consulta.
- Todo o conteúdo relevante (Partes I a X: Estatuto da OAB, Código de Ética, LGPD, Protocolo Anti-Alucinação, Fluxos de Triagem, 12 Áreas do Direito, Prazos Processuais e Prompt de Sistema) foi convertido e modularizado nos arquivos em `/prompts/`:
  - `prompts/system.md` (e `system_cliente.md`): Prompt mestre para atendimento ao cliente leigo.
  - `prompts/system_equipe.md`: Prompt técnico para uso interno do escritório.
  - `prompts/areas/*.md`: Módulos de triagem, normas e checklists para cada uma das 12 áreas do Direito.
